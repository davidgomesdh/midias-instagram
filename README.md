# midias-instagram

Arquivos que o Metricool baixa para agendar os posts do Instagram das marcas do David (GymLog e as próximas).
Só contém o que já vai ser público no Instagram. A história é refeita a cada envio (commit único) para o repositório não crescer; os arquivos de posts já publicados são apagados depois de 3 dias.

Gerido pela skill instagram-marcas (scripts/publicar.mjs). Não usar para a DGtec.
